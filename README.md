# Patitas — Clínica veterinaria

Proyecto académico del Hito 2. Sitio en HTML, CSS propio y JavaScript, sin frameworks ni dependencias.

## Ver el sitio

Abre `index.html` en tu navegador. Incluye estructura semántica, formulario HTML5 con etiquetas y correo obligatorio, navegación Flexbox, una media query para pantallas de hasta 600 px y un botón de modo oscuro.

El formulario solo demuestra la validación del navegador. No envía ni guarda datos. El nombre y los servicios son ilustrativos; reemplázalos con la información real de la veterinaria.

## Publicar en GitHub Pages

1. Sube la rama `main` al repositorio.
2. En GitHub abre **Settings → Pages**.
3. Selecciona **Deploy from a branch**, rama **main**, carpeta **/ (root)** y guarda.
4. Espera a que termine la publicación y abre la dirección que muestre GitHub.

Repositorio configurado: https://github.com/rosemarycalizaya-alt/veterinaria-wen

Dirección prevista al activar Pages: https://rosemarycalizaya-alt.github.io/veterinaria-wen/

## Revisión antes de entregar

En DevTools, prueba a 375 px y en escritorio: no debe aparecer desplazamiento horizontal. Comprueba el modo oscuro, los enlaces del menú y la validación de correo. Entrega las URL del repositorio y del sitio publicado.
